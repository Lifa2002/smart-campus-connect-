# 🎓 Richfield Connect — Student Social & Community Platform

A dynamic, multi-page front-end web application designed to connect students, facilitate community engagement, and share updates. Built as a comprehensive web technology project, it features simulated user authentication, persistent data handling, a live community feed, and custom profile management.


---

## ✨ Key Features

- **User Authentication Workflow:** Simulated sign-up and login logic (`auth.js`) with form validation and state handling.
- **Interactive Community Feed:** Dynamic feed system (`feed.js`) allowing users to post updates, interact, and view campus content.
- **User Profiles:** Dedicated profile management pages (`profile.js`) where student details and activity can be viewed and managed.
- **Client-Side Data Persistence:** Utilises browser **Local Storage** to retain user session data, posts, and profile details across page reloads without requiring an external database.
- **Responsive Multi-Page Architecture:** Structured across multiple HTML pages (`index.html`, `feed.html`, `profile.html`, `signup.html`, `about.html`) styled with custom CSS.

---

## 🛠️ Tech Stack

- **Markup & Structure:** HTML5 (Multi-page layout)
- **Styling:** CSS3, Responsive Design
- **Scripting:** JavaScript (ES6+), jQuery
- **Data Storage:** Browser Local Storage
- **Version Control & Deployment:** Git, GitHub, Netlify

---

## 📱 Project Structure

- `index.html` — Landing and entry page
- `signup.html` / Login — User onboarding and authentication
- `feed.html` — Main community dashboard and post feed
- `profile.html` — User account and settings view
- `about.html` — Project background and overview
- `/js` — Modular JavaScript files handling auth, feeds, and profiles
- `/css` — Custom stylesheets
