About Richfield Connect

Richfield Connect is a dynamic student social platform prototype developed for Richfield students. The platform allows users to create profiles, share posts, interact with peers, and build academic connections within a secure institutional environment. This project was developed using HTML5, CSS3, JavaScript, jQuery, and browser localStorage to demonstrate responsive design, dynamic interactivity, and client-side data persistence.
